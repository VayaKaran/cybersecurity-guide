# Visual Asset Statement

Cybersecurity Guide 2 contains more than 100 visual assets.

These assets were created/generated specifically for this project by
the author, Karan B. Vaya.

No visual asset was intentionally copied from another cybersecurity guide, website, textbook, or third-party project.

The visual material was created to support explanations of cybersecurity concepts and improve the educational structure of the
guide.

## Purpose of the Visuals

The visual assets are used for:

- Concept explanations
- Attack/defense models
- Network concepts
- Security workflows
- Learning diagrams
- Comparisons
- Memory aids
- Technical illustrations
- Chapter summaries

## Authorship

The visual assets form part of the original project work and should be considered together with the written curriculum and technical
documentation when evaluating the project.
