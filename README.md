## About This Project

Cybersecurity Guide 2 is a self-directed cybersecurity learning
project developed to build a strong theoretical and analytical
foundation before moving into advanced practical security labs.

The guide focuses on understanding systems and security concepts
before depending on automated security tools.

The project covers areas including:

- Cybersecurity mindset and risk
- Linux and Termux
- Networking fundamentals
- Web security
- Log and incident analysis
- Attack and defense mapping
- Security documentation
- Cyber law and ethical boundaries
- Social engineering awareness
- Cybersecurity career foundations

## Project Purpose

I developed this project as part of my independent cybersecurity
learning journey and portfolio.

The project was designed around a theory-first approach, particularly
while working with limited computing resources.
